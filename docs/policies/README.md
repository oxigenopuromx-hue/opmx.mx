Este directorio está reservado para políticas institucionales futuras de
OPMX (p. ej. política editorial, política de correcciones, política de
privacidad, política de datos abiertos, política de IA — ver la lista de
"documentos derivados" en `docs/strategy/OPMX_PRODUCT_ROADMAP_v1.0.md`
§53).

**Estado actual: vacío.** Conforme a `OPMX_PRODUCT_ROADMAP_v1.0.md` §53:
"No todos deben crearse inmediatamente. Se crearán cuando se aproximen a
la etapa que los necesita." No existe ninguna política institucional
formalizada como documento independiente todavía.
